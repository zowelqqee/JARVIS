# JARVIS Intent Classifier

ML-модуль для классификации намерений пользователя в голосовом ассистенте JARVIS.

## Что делает
Принимает текстовую фразу, возвращает интент и уверенность (0.0–1.0).
Используется для мониторинга и логирования команд пользователя.

## Стек
- scikit-learn: TF-IDF + LogisticRegression
- FastAPI: REST endpoint
- MLflow: логирование экспериментов
- joblib: сохранение модели

## Датасет
4200 фраз, 6 интентов: open_app, close_app, minimize_app, maximize_app, turn_on, turn_off.
Сгенерированы скриптом с вариациями, опечатками и шумовыми префиксами.

## Результаты
Accuracy на val: 99.88%

## Запуск API
uvicorn intent_api:app --reload
POST /predict {"text": "открой браузер"} → {"intent": "open_app", "confidence": 0.97}

## Архитектурное решение
JARVIS использует Google Live API — аудио идёт напрямую в Gemini.
Классификатор работает на уровне мониторинга, не как блокировщик.
Для блокировки на уровне Python нужен локальный STT (Whisper) — следующий шаг.

## Варианты развития
1. Локальный Whisper STT — классификатор получает текст до Gemini
2. Speaker identification — реагировать только на голос владельца
3. Расширить датасет реальными фразами из логов JARVIS
