## 🧠 Intent Classifier

ML-модуль для классификации намерений пользователя.

- **Стек:** scikit-learn, TF-IDF + LogisticRegression
- **Датасет:** 4200 фраз, 6 интентов, сгенерированы скриптом
- **Accuracy:** 99.88% на val выборке
- **Роль в архитектуре:** мониторинг и логирование интентов. Прямая блокировка невозможна из-за Google Live API — аудио идёт в Gemini до транскрипции.
